# 한국어 TTS 표기·발음 교정

검색 자료·매뉴얼·AI 답변 원문을 수정하지 않고 음성 입력만 교정합니다. 재시작 이후 새로 합성하는 음성에 적용되며, 반복 방송은 해당 사건에서 교정해 만든 WAV를 재사용합니다.

## 적용 위치

- `voice/pronunciation.py`: 단위·범위·음수 보존과 로컬 발음 사전.
- `voice/tts.py`: 특수문자 제거 전에 숫자 단위를 한글로 풀어 씁니다. Gemini에는 이 공통 처리만 적용합니다. Gemini 실패 후 로컬 전환 시 원문에서 로컬용 발음을 다시 준비합니다.
- `voice/ppaso_wrapper.py`: 직접 PPASO 래퍼를 호출하는 경우에도 합성 직전에 로컬 교정을 적용합니다.
- PYTTSX3의 한국어 경로도 로컬 교정을 사용하지만 설치된 음성 자체의 품질을 개선하는 기능은 아닙니다.

## 교정 범위

| 종류 | 예 | 음성 입력 |
|---|---|---|
| 화학식 | CO2/CO₂, N2/N₂, O2/O₂, H2O/H₂O | 이산화탄소, 질소, 산소, 물 |
| 단위 | m, cm, mm, km, kg, mg, L, mL 및 등록된 호환 문자 | 미터, 센티미터, 밀리미터, 킬로미터, 킬로그램, 밀리그램, 리터, 밀리리터 |
| 면적·부피 | ㎡/m², ㎥/m³ | 제곱미터, 세제곱미터 |
| 온도·비율 | 75℃, -5도, 80% | 섭씨 75 도, 마이너스 5도, 80 퍼센트 |
| 속도 | 30km/h, 0.5m/s | 시속 30 킬로미터, 초속 영 점 오 미터 |
| 범위 | 10~15m, 3~5분 | 10 미터에서 15 미터, 3분에서 5분 |
| 소수·쉼표 수량 | 1.05m, 1,500m | 일 점 영오 미터, 천오백 미터 |
| 현장 약어 | E-STOP, E/V홀 | 이 스톱, 엘리베이터홀 |
| 기타 약어 | ABC, BC, CPR, GPS, AED, AI | 명시된 한글 철자 읽기 |
| 구역 목록 | A·C구역 | A구역과 C구역 |

ABC·CPR 등의 기본 철자 읽기는 기존 PPASO에서도 맞게 정규화되며, 교정 목록에 있다고 오발화가 청취로 확인됐다는 뜻은 아닙니다. CO2는 사용자가 오발화를 보고했으며, 거리·소수·일부 단위·E-STOP은 설치된 정규화 코드의 잘못된 입력 변환을 확인했습니다. 최종 발음과 억양은 실제 스피커로 확인해야 합니다.

## 보수적으로 유지하는 표기

- A3, KFSC101 같은 위치·규격 식별자, IP 주소와 버전 번호는 수량으로 바꾸지 않습니다.
- NaHCO3, H2O2 등 미등록 화학식을 부분 문자열로 추정 변환하지 않습니다.
- kg/cm2 같은 미등록 복합 단위, 비율·시각·분수·수식은 별도 검토 대상입니다. 기존 공통 기호 정리까지 모두 보존된다는 의미는 아닙니다.
- 명·개·시간의 한자어/고유어 읽기를 문맥 없이 일괄 변환하지 않습니다.
- PDF 추출 오류·HTML 잔재·깨진 글자는 발음 사전으로 뜻을 추정하지 않고 원본 자료를 확인합니다.

## 점검과 비교 음성

프로젝트 가상환경에서 다음 명령을 실행합니다.

```bash
python tools/audit_tts_pronunciation.py
python tools/audit_tts_pronunciation.py --audio
```

`output/tts_pronunciation/audit.md`에 매뉴얼 표기 목록과 전처리 비교 결과가 만들어집니다. `--audio`는 API를 사용하지 않고 로컬 PPASO로 원문 직접 합성(`*_raw.wav`)과 교정 합성(`*_fixed.wav`) 여섯 쌍을 생성합니다. 입력·출력 대응은 `clips.json`에 기록합니다. raw는 앱의 공통 전처리를 거치지 않으므로 앱에서 이미 적용하던 119 교정 등과 구분해야 합니다.

실제 청취에서는 CO2, 거리, 소수, 음수·온도·퍼센트, 범위, 현장 약어를 우선 비교하고, 긴 전문어(하향식피난구·경량칸막이·유증기 등)는 문장 안에서 추가 확인합니다. 일반 한국어 단어를 발음대로 임의 철자 변경하면 다른 문맥의 발음이 나빠질 수 있으므로 확인된 사례만 추가합니다.
