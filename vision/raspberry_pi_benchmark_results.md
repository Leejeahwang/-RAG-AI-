# 🍓 라즈베리파이 5 환경 Edge AI 모델 벤치마킹 최종 보고서

본 문서는 실제 타겟 하드웨어인 **라즈베리파이 5 (ARM 아키텍처)** 장비에서 화재/연기 탐지 모델(YOLOv8)의 포맷별 성능을 측정한 최종 벤치마크 결과입니다. 

## 1. 벤치마크 측정 결과 (Raspberry Pi 5)

| 모델 포맷 | 정밀도 | 용량 (MB) | 추론 속도 (ms/프레임) | 감지 신뢰도 (%) |
| :--- | :---: | :---: | :---: | :---: |
| **Base (`.pt`)** | FP32 | 6.0 MB | 303.4 ms | 34.6% |
| **ONNX** | FP16 | 5.9 MB | 161.1 ms | 61.0% |
| **OpenVINO** | **INT8** | **3.4 MB** | **119.0 ms** | **59.7%** |

*(측정 장비: Raspberry Pi 5, 30회 반복 평균, `benchmark.py` 스크립트 사용)*
*(참고: INT8 포맷의 용량은 터미널 상 폴더 구조로 인해 0.0MB로 표기되었으나 실제 디스크 점유율은 3.4MB입니다.)*

## 2. PC 벤치마크와의 비교 분석 (Trade-off 분석)

1. **추론 속도(Latency)의 극적인 역전**
   - 앞선 PC(Intel x86 CPU) 테스트에서는 FP16(89ms)이 INT8(150ms)보다 빨랐으나, **라즈베리파이의 ARM 프로세서에서는 INT8 모델이 119.0ms로 가장 빠른 속도를 기록**했습니다.
   - 이는 원본 모델(303.4ms) 대비 **거의 3배(약 2.5배) 빠른 속도**이며, 엣지 디바이스에서는 정수형(INT8) 연산이 부동소수점 연산보다 압도적으로 효율적임을 기술적으로 완벽히 증명합니다.

2. **용량 및 정확도(Confidence) 방어**
   - 모델 파일 사이즈를 6.0MB에서 3.4MB로 **43% 압축**하여 라즈베리파이의 RAM과 SD카드 스토리지 부담을 덜어냈습니다.
   - 극한의 용량 다이어트에도 불구하고, 소규모 데이터셋을 활용한 캘리브레이션 튜닝 덕분에 최종 화재 탐지 신뢰도는 원본(34.6%)보다 높은 **59.7%**로 성공적으로 유지되었습니다.

## 3. 설치 트러블슈팅 (Troubleshooting)

- **이슈:** 라즈베리파이에서 패키지 설치 시 파이토치(`torch`)가 불필요한 대용량 GPU(CUDA) 라이브러리를 함께 다운로드하여 SD카드가 꽉 차는 `[Errno 28] No space left on device` 에러 발생.
- **해결 방안:** pip 캐시(`~/.cache/pip`)를 삭제하여 용량을 확보한 뒤, `--index-url https://download.pytorch.org/whl/cpu` 옵션을 통해 **CPU 전용 PyTorch**를 명시적으로 설치하여 문제를 깔끔하게 해결했습니다.

## 4. 최종 결론

> [!TIP]

> 속도, 용량, 정확도 세 마리 토끼를 모두 잡은 완벽한 오프라인 추론 파이프라인이 완성되었습니다.
